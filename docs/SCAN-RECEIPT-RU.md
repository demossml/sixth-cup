# Сканировать чек (клиент)

- Интерфейс на русском.
- QR проверяется локально (подпись кассы), затем **POST /api/sync**.
- Карта на экране — только `card` с сервера.
- Без сети чек в очереди; начисление после успешного sync.
- Основной путь на кассе: POST /api/devices/sales (онлайн) — гостю скан может не понадобиться.
