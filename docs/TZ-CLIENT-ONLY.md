# ТЗ: клиент только для гостя

## Цель
`app.*` — только клиент. Без кассы, без dev, без админки.

## Убрать из frontend (клиент)
- `/cashier`, CashierPage
- `/dev`, DevPage  
- `/admin` и любые ссылки
- «Для сотрудников» в профиле

## Оставить
Онбординг, логин, карта, меню, акции, профиль, sync, logout.

## Остальное
Владелец → admin.* / frontend-admin
Касса → не в клиенте (будущий отдельный канал / Android)
