# Макет меню — шаблоны и мастер «Новое меню» (3.2, 3.4)

Продолжение [AUDIT-MENU-LAYOUT-STAGE3-PLACES.md](./AUDIT-MENU-LAYOUT-STAGE3-PLACES.md). Сделаны
**3.2** (мастер создания) и **3.4** в части шаблонов.

## Шаблоны листа (3.4, MVP)

`backend/src/modules/admin/menuTemplates.ts` — 6 шаблонов. Шаблон это не картинка, а правила раскладки:

| id | Что делает |
|---|---|
| `classic-two-column` | плотный лист: 2 колонки, позиция 5 %, секция 5,5 %, тема «Классика» |
| `one-column-large` | крупный список: 1 колонка, позиция 8 %, секция 7 % |
| `compact-price-list` | прайс: 2 колонки, позиция 4,2 %, узкий зазор |
| `photo-menu` | фотоменю: позиция 11 %, тема «Сезон» |
| `dark-bar` | вечерний лист: позиция 6 %, тема «Тёмный» |
| `screen-16-9` | витрина на монитор: формат 16:9, отступ сверху 15 % |

- `GET /menu-layouts/templates` — список для UI (id, название, цель, правила).
- `POST /menu-layouts/:id/seed-from-catalog { template }` — раскладывает каталог по шаблону **и ставит тему шаблона**.
- `POST /menu-layouts/:id/layout { template }` — пересобрать существующий макет по другому шаблону:
  секции и позиции остаются, меняются колонки, плотность и отступы.
- В редакторе это drawer «Формат и шаблон»: набор кнопок-шаблонов (виден при `VITE_MENU_LAYOUT_V2=1`).

## Мастер «Новое меню» (3.2)

Диалог создания теперь спрашивает **с чего начать**:

- **«Собрать из каталога»** (по умолчанию) — после создания сразу вызывается seed с выбранным шаблоном,
  человек попадает на готовый лист, а не на пустой холст; под селектором — цель шаблона словами.
- **«Пустой лист»** — прежнее поведение.
