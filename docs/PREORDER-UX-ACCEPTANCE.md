# Приёмка UX: предзаказ PWA → касса (баннер, ETA, бан)

Дата: 07.11.2026. План: [`PREORDER-ROLLOUT-PLAN.md`](./PREORDER-ROLLOUT-PLAN.md).
Журнал этапов: [`PREORDER-STAGE-REPORTS.md`](./PREORDER-STAGE-REPORTS.md).

Как проверяли: backend в `NODE_ENV=production` (отдаёт собранный `frontend/dist`) на одном origin
с API, БД — копия рабочей (`/tmp/e2e.db`), две точки, у товаров разные `recipe_seconds`,
`evotor_stores.local_store_id` + `product_store_links` заполнены. Админка — собранный `dist`
за статическим прокси на тот же backend. Касса — `POST /api/devices/enroll` + device-токен.

Вердикты: **PASS** — проверено и работает, **FAIL** — дефект (исправлен, см. журнал),
**BLOCKED** — нельзя проверить в этом окружении.
