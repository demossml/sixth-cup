# PWA: QR сразу на главной

## Зачем
В очереди у кассы лишний тап «Показать QR» мешает. Паттерн wallet/loyalty: открыл приложение — код уже на экране.

## Поведение
- `/` (Карта): крупный signed proof QR (`best.token`) + `cardCode` без обязательного тапа.
- Тап по QR — опционально `/card-qr` на весь экран.
- Прогресс стаканов — компактная полоска в шапке, не вытесняет QR.
- Screen Wake Lock best-effort на главной, пока есть proof.
- Invite / кэшбэк ниже; списания в PWA нет.
- История, backend policy B, Android, admin — без изменений в этом патче.

## Проверка
1. Открыть app → QR виден без нажатий.
2. Номер карты крупно под QR.
3. Airplane mode после первого sync → QR остаётся.
4. Скан Эвотор с главного экрана.
