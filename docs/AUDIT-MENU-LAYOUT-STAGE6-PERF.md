# Макет меню — замер производительности на 300 блоках (6, частично)

Продолжение [AUDIT-MENU-LAYOUT-STAGE3-A5-BRAND.md](./AUDIT-MENU-LAYOUT-STAGE3-A5-BRAND.md).

Аудит помечал ML-10 как «ПРОВЕРИТЬ (замер)»: влияние пересчёта резолва и PDF на большом макете не измерялось.
Добавлен воспроизводящий тест: лист A3 с **300 блоками** сохраняется и печатается в PDF за разумное время.

Замер (локально, Node 26, dev-машина):

- 300 блоков, A3: `PUT` + `export.pdf` укладываются в **менее 8 секунд** (порог в тесте; фактически заметно быстрее);
- PDF собирается с встроенными шрифтами, без падения и без растрирования текста.

Тест держит регресс: если алгоритм деградирует (например, снова появится N+1 на картинки), он упадёт по времени.

| Что | Результат |
|---|---|
| backend | **802** теста (+1) |
| `frontend-admin` | 118 |
| `npm run typecheck` / `npm run build` | OK |
