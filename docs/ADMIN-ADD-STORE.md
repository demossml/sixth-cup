# Инструкция: как добавить кофейню, чтобы гость мог её выбрать

Для владельца. Всё делается в админке, без кода и без SQL. Примерное время на одну точку — 3 минуты.

Адреса экранов (админка): `#/cash` — «Касса», `#/system` — «Система».

---

## 0. Что должно быть готово заранее

| Что | Где | Зачем |
|---|---|---|
| Организация (название, юрлицо, ИНН) | «Система» → Организации | Без организации точка не создастся |
| Админка на версии `72ccda8` или новее | — | форма «Новая кофейня» появилась в этом коммите; на Mini нужно `git pull` + рестарт |

Если организации нет: **Система → Организации → Добавить** → название, юрлицо, ИНН → Сохранить.

---

## 1. Создать точку

1. Откройте **Касса** (`#/cash`).
2. Найдите блок **«Кофейни в приложении»** (над «Устройства»).
3. Заполните три поля формы «Новая кофейня»:

| Поле | Что вписать | Пример |
|---|---|---|
| **Новая кофейня** | Название, которое увидит гость. Короткое, с ориентиром | `6.7 Coffee на Ленина` |
| **Адрес** | Улица, дом — как в картах. Город не нужен, если он один | `ул. Ленина, 12` |
| **Организация** | Выбрать из списка (появился на шаге 0) | `ООО «6.7»` |

4. Нажмите **«Добавить кофейню»**. Появится карточка точки, тост «Кофейня добавлена».

> Название + адрес — это то, что видит гость на экране выбора кофейни. Пишите так, как человек
> объяснил бы другу, где забрать кофе: «6.7 Coffee на Ленина · ул. Ленина, 12».

---

## 2. Часы работы (от них зависит, можно ли заказать)

В карточке точки:

1. **Открытие** и **Закрытие** — время в формате `08:00` / `21:00`. Это общий режим.
2. Нужны разные часы по дням — включите галочку **«Разные часы по дням»** и задайте 7 строк
   Пн…Вс. Выходной — галочка **«выходной»** (точка закрыта весь день).
3. Нажмите **«Сохранить кофейню: <название>»**.

Что видит гость:

- «Открыто · до 21:00» — можно отправлять заказ;
- «Закрыто · 08:00–21:00» — карточка точки в списке неактивна, заказ в неё отправить нельзя;
- часы не заданы — точка считается открытой, рядом просто написано «Открыто».

## 3. Координаты — самое важное для «выбрать точку»

Координаты нужны для трёх вещей: точка на схеме города, «Найти ближайшие» (сортировка по
расстоянию) и кнопка «Маршрут» в Google/Apple/Яндекс картах.

**Не вводите числа руками** — легко ошибиться в одном знаке и увести точку на другой конец города.
В карточке есть поле **«Ссылка из карты»**:

### Вариант А. Яндекс Карты (рекомендую)

1. Откройте `yandex.ru/maps`, найдите свою кофейню, кликните по зданию/метке правой кнопкой →
   **«Что здесь?»**. Внизу появится карточка с координатами и кнопкой «Поделиться» → **«Скопировать ссылку»**.
   Либо просто скопируйте адрес из строки браузера — там есть `?pt=долгота,широта`.
2. В админке вставьте ссылку в поле **«Ссылка из карты»**.
3. Нажмите **«Заполнить»** — числа «Широта» и «Долгота» подставятся сами (порядок Яндекс отдаёт
   наоборот, мы это разворачиваем).
4. **«Сохранить кофейню: <название>»**.

Пример: `https://yandex.ru/maps/?pt=37.617300,55.755800&z=17` → широта `55.7558`, долгота `37.6173`.

### Вариант Б. Google Карты

Найдите точку → правой кнопкой по метке → первая строка (координаты) копируется кликом.
Или скопируйте адрес страницы: в нём есть `/@55.755800,37.617300,17z`.

### Вариант В. Apple Карты

Найдите точку → «Поделиться» → «Скопировать ссылку». В ссылке будет `?ll=55.755800,37.617300`.

### Если «Заполнить» пишет «Не нашёл координаты»

- Ссылка ведёт на город/поиск, а не на точку (`.../213/moscow/`) — откройте саму кофейню и
  скопируйте ссылку ещё раз.
- Можно вписать пару чисел строкой `55.7558, 37.6173` (широта, долгота) и нажать «Заполнить».

### Проверка точности (10 секунд)

Нажмите «На карте» на экране выбора кофейни в приложении — откроется карта ровно на вашей точке.
Если метка стоит не там — вернитесь в админку и повторите шаг 3.

## 4. Проверить глазами гостя

1. В приложении: **Меню** → «изменить» рядом с названием кофейни (или `/pick-store`).
2. Ожидаемо: ваша точка в списке с адресом и часами, точка на схеме, кнопки «Google · Apple · Яндекс».
3. Выберите точку → **«Забрать здесь»**. Название появится в корзине («Где заберёте»).
4. Если точка не появилась — потяните экран вниз (обновление каталога) или перезайдите: приложение
   кэширует меню и обновляет его при синхронизации.

---

## 5. Частые ошибки

| Симптом | Причина | Что делать |
|---|---|---|
| Нет блока «Кофейни в приложении» | Старая версия админки | `git pull` на Mini, `npm ci`, `npm run build`, рестарт сервиса |
| «Нужны название, адрес и организация» | Не выбрана организация | Создать её в «Системе» |
| Точка есть, но в приложении её нет | Каталог закэширован | Обновить меню в приложении (pull-to-refresh) |
| Точка на схеме в центре, «Маршрут» ведёт по адресу | Не заданы координаты | Шаг 3 |
| «Закрыто» днём | Часы заданы неверно / сегодня выходной | Проверить «Разные часы по дням» |
| Гость не может отправить заказ | Точка закрыта или заказ уже активен | Проверить часы; активный заказ надо забрать или отменить |

---

## 6. Что ещё понадобится для полного запуска предзаказа

| Шаг | Где | Зачем |
|---|---|---|
| Устройство кассы (код регистрации) | «Касса» → «Устройства» → «Создать код» | Кассир принимает заказы и ставит «Готов» |
| Время приготовления, минуты | «Предзаказы» → настройки точки | Гость видит реальный ETA |
| Часы бана за невыкуп | «Предзаказы» → настройки точки | Защита от спама пустыми заказами |
| Товары с «Считается стаканом» | «Меню» → карточка товара | Прогресс «6-й стакан в подарок» |

Порядок такой: организация → точка (+ часы + координаты) → устройство → время приготовления →
проверить заказ с телефона.
