# Добавки и рецепты

## Admin
- Вкладки **Добавки**, **Схемы**
- У товара: схема добавок + текст рецепта + себес
- Одна схема → много товаров (копирование через «copy from» при создании схемы)

## Directory
`modifiers`, `modifierSchemes`, у product: `modifierSchemeId`, `recipeText`, `recipeCostRub`

## Касса
- Добавки только из схемы товара
- Долгий тап по товару → рецепт
