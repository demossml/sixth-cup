# Себестоимость / техкарты — внедрение

Дата: 2026-11-08

## Что сделано

### Backend
- Миграция `056_cost_techcards.sql`: категории, ингредиенты, рецепты, строки рецепта.
- Модуль `backend/src/modules/admin/cost.ts`, подключён в `admin/routes.ts`.
- API (все под `/api/admin`, admin-token):
  - `GET/POST /cost/categories`
  - `GET/POST/PUT /cost/ingredients`, `GET .../usage`, `POST /cost/ingredients/bulk`
  - `GET/POST/PUT/DELETE /cost/recipes`
  - `GET /cost/summary`
  - `POST /cost/ai/parse` — черновик из текста (heuristic без ключа; DeepSeek если настроен), **без записи в БД**
- Формулы: цена/ед. = фасовка÷кол-во; себес = сумма **base**-строк; optional отдельно; наценка → расчётная розница.
- В рецепт нельзя добавить ингредиент без фасовки и цены.
- Тесты: `backend/src/__tests__/cost-techcards.test.ts`

### Admin UI
- Пункт меню **«Себестоимость»** (`Shell` + route `/cost`).
- Страница `frontend-admin/src/pages/Cost.tsx`: вкладки Ингредиенты / Рецепты / Сводка.
- «+ Категория», «Заполнить с ИИ» → preview → bulk create.
- Рецепт: строки base/optional (стаканы, крышки, молоко…), наценка, розница, маржа.
- CSV на сводке.

### Не сделано (по плану — после MVP)
- Автоприменение розницы в `products` / Эвотор
- Связь с `stock_items` / приходками
- Прогноз расхода «100 капучино → X л»
- OCR файлов (только текст в AI parse; фото можно вставить как описание вручную)

## Деплой
1. `git pull` / накат архива
2. build backend + frontend-admin
3. restart API (миграция 056 применится при старте)
4. Админка → Себестоимость
