# Макет меню — формат A5 и палитра бренда (3.4, частично)

Продолжение [AUDIT-MENU-LAYOUT-STAGE3-CANVAS-SNAP.md](./AUDIT-MENU-LAYOUT-STAGE3-CANVAS-SNAP.md).

## Формат A5

Добавлен `a5_portrait` (148 × 210 мм, 419,53 × 595,28 pt) в backend (`LAYOUT_FORMATS`, zod `FORMATS`)
и в клиентский `LAYOUT_FORMATS`. Доступен в мастере создания, в списке форматов и в drawer «Формат и шаблон»;
PDF, безопасная область и кегль считаются по общим правилам (`sheetGeometry` — доли ширины листа).

## Палитра бренда

`BRAND_COLORS` — семь токенов из аудита (`#002FA7`, `#001F6B`, `#E6ECFF`, `#F6F3EE`, `#FFFFFF`, `#1B1A17`, `#C8A26E`).
В панели «Оформление» появился ряд кружков: клик ставит акцент из палитры бренда, при этом свободный выбор
цвета остаётся — это и есть «выйти из бренда» по явному действию. Шаблоны (этап 3.4) стартуют с палитры.
