## Что сделано
- Главная: статус → кружки (масштабируются, до 8 в ряд, больше — 2 ряда) → одна фраза «Ещё N стаканов до бесплатного» / оранжевая плашка «Подарок: … — скажите бариста» → QR 300 px и номер крупно → кэшбэк → приглашение («ссылка для друга, не для кассы») → установка → восстановление → купоны.
- Установка: `beforeinstallprompt` ловится на уровне модуля; на главной баннер — карточка в потоке **под** QR, на остальных экранах — плавающий; на fullscreen QR скрыт.
- Статус данных: `Нет сети` (QR работает, время данных) ≠ `Давно не обновлялось` (> 5 мин при сети) ≠ `Обновлено 14:05`.
- QR рендерится в физических пикселях (DPR ≤ 3); Wake Lock с повторным захватом при возврате во вкладку.
- Профиль: создать/копировать/скачать код восстановления, восстановить (вставка или сканирование), сброс только после предложения сохранить + подтверждение (bottom sheet вместо `confirm()`).
- История: группы по дням, «+4,50 ₽», склонение стаканов, сохранённая копия с временем без сети.
- Кофейни (из directory, работает офлайн), safe-area, цели ≥ 44 px на главных действиях, `prefers-reduced-motion`.
- Первый запуск: после выдачи карты сразу sync → QR без тапа. `ensureGuest` — single-flight.
- Backend не менялся.

## Референсы: взять / не брать / как в 6.7
Это общеизвестные публичные паттерны; закрытых метрик не приводим, свежие страницы в этой сессии не перечитывались.

| Референс | Берём | Не берём | В 6.7 |
|---|---|---|---|
| Apple / Google Wallet | код сразу, светлое поле, номер под кодом, минимум chrome | push-обновления pass | QR 300 px на белом + номер 34 px |
| Starbucks Rewards | «сколько осталось» текстом, код на первом экране | order-ahead, звёздные баллы | «Ещё N стаканов» |
| Luckin / Tims (штампы) | заметный подарочный слот | игровые механики | слот «в подарок», оранжевый акцент |
| Stamp-карты | видимые заполненные/пустые | абстрактные проценты | кружки |
| PWA install | установка не блокирует ценность; iOS — подсказка «Поделиться» | модальный блок до использования | карточка под QR, «Позже» на 14 дней |

Антипаттерны (не делаем): мелкий QR, 4–5 табов, баллы без «осталось N», обязательный телефон/SMS, баннер поверх кода, обязательный тап «Показать QR».
