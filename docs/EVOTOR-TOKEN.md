# Токен Облака Эвотор — фиксированный

Как в **workApp**: один долгоживущий токен в серверном `.env`.

```bash
EVOTOR_API_TOKEN=<токен_от_Эвотор>
# опционально, если нужен прокси как на Mac mini workApp:
# EVOTOR_PROXY_URL=http://127.0.0.1:….
```

- Заголовок запросов: `X-Authorization: <token>`
- **Не** настраиваем получение токена через webhook `/user/token` и push ради токена.
- Токен **не** в Git, **не** в APK, **не** в чат с агентами без нужды.
- Владелец вставляет значение на сервере сам.

Webhook create/verify/token в кабинете **можно не заполнять** для этой схемы.
