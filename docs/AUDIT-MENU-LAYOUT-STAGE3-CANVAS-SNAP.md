# Макет меню — прилипание на холсте (3.5, частично)

Продолжение [AUDIT-MENU-LAYOUT-STAGE5-AI.md](./AUDIT-MENU-LAYOUT-STAGE5-AI.md). Сделан пункт **3.5**
в части точной подгонки: блоки прилипают к полям листа и краям соседей.

## Что добавлено

`snapRect(rect, others, threshold = 0.8 %)` в `frontend-admin/src/lib/menuLayout.ts` — чистая функция:

- цели по X: левое поле, правый край листа (с учётом ширины блока), центр листа, а также левый/правый край
  и центры каждого соседнего блока, включая «встык» (сосед справа/слева);
- цели по Y — те же правила;
- из подходящих целей выбирается **ближайшая**, поэтому блок не дёргается между линиями;
- результат прогоняется через `clampRect`, то есть за лист всё равно не выйдет.

В редакторе прилипание включено при перетаскивании; **Alt** отключает его, когда нужно поставить «как хочу».
Подсказка в шапке редактора обновлена.
