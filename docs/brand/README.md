# Бренд 6.7 Coffee — исходник и ассеты

## Источник

`docs/brand/67-logo-source.jpg` — исходный JPEG от владельца (297×397, синий маскот с
бирюзовым сердцем «6.7 COFFEE», белый фон, без прозрачности).

Других источников нет: стоковые персонажи и «нарисованные от себя» логотипы не используются.

## Правило точки: только квадрат

Между **6** и **7** — квадратная точка (■), не круглая «.» и не средняя точка.
В растре она **нарисована**, а не взята из шрифта:

- в мастере точка заменена на прямоугольник **7×7 px** (в координатах исходника),
  низ — на базовой линии цифр, цвет = цвет цифр (`rgb(241,245,248)`);
- старая скруглённая точка стёрта, область залита интерполяцией по горизонтали и
  вертикали (сохраняет градиент сердца — без видимого прямоугольника);
- проверка геометрии в готовом мастере: bbox 8×8 при **fill = 1.00** — это квадрат,
  а не круг (у круга fill ≈ 0.78);
- в тексте UI (`6■7 Coffee`) точка нарисована CSS-элементом `.brand-dot`
  (`width = height = 0.16em`, `background: currentColor`) — тот же приём в PWA и админке;
  для скринридеров рядом лежит `sr-only` «.», чтобы читалось «6.7 Coffee».

## Как сделан прозрачный мастер

1. Фон вырезан **заливкой от краёв** (flood fill по почти-белым пикселям, начиная с рамки),
   а не глобальным «убрать белый». Иначе пробились бы белые буквы «6.7 COFFEE» на сердце
   и светлая морда.
2. Результат обрезан по содержимому, вписан в квадрат с полем 4% → `logo-mark.png` (512×512, RGBA).
3. Иконки — тот же мастер на белом фоне: маскот занимает 80% квадрата (безопасная зона maskable).

подложке — иначе синий на синем.

## Перегенерация иконок

```bash
cd frontend && npm run icons        # icon-192/512 + favicon-16/32/48/64 из logo-mark.png
```

После масштабирования точка **перерисовывается жёстким квадратом** (`stampDot` в скрипте):
LANCZOS смазывал углы (получалось 3×4, fill 0.85), и на 16–48 px точка выглядела круглой.
На 16–32 px сторона не меньше 2 px — иначе 1 px-точка визуально исчезает.

Почему favicon кадрируются по-разному: на 16–32 px весь маскот занимает ~20 px, и надпись
на сердце становится субпиксельной — квадрат превращается в пятно. Поэтому для мелких
размеров берётся плотный кроп «6■7» (координаты `MICRO` в скрипте), для 48–64 — кроп с
`COFFEE` (`COMPACT`). При любом кропе точка остаётся квадратом, дорисованных элементов нет.

Проверка приёмки (визуально, все размеры):

| Размер | Что видно |
|---|---|
| 512 / 192 | весь маскот, между 6 и 7 — квадрат |
| 64 / 48 | «6■7 COFFEE» на сердце, квадрат читается |
| 32 | «6■7», точка 2×2 px — квадрат |
| 16 | «6■7», точка 2×2 px (fill 1.00) — минимальный читаемый квадрат |

Скрипт `frontend/scripts/make-icons.mjs` собирает только производные от `logo-mark.png`;
сам мастер правится в графическом редакторе и коммитится как PNG.

Админка иконки не генерирует — они лежат готовыми в `frontend-admin/public/`.
