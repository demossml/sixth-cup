## Ключевые решения

- **P0-1**: `backend/src/modules/orders/pricing.ts` — единственное место, где из `modifierId`/`volume`
  получается цена и отображаемое имя. Клиентские `priceRub`/`name` игнорируются. `modifierId` обязан
  принадлежать схеме выбранного товара, иначе `400`. Quote использует тот же резолвер (B-07 не отложен).
- **P0-4**: challenge-proof для публичного ключа не вводился (менять контракт APK в этой волне нельзя).
  Риск закрыт TTL + одноразовостью + лимитами; полноценный challenge — кандидат в P1.
- **P0-3**: `sc.ord` = id очереди. Fallback на `sc.ord` работает только для uuid-подобного значения,
  которое существует как заказ, и пишет deprecation-предупреждение в лог.
- **P0-6**: тело оплаты необязательное — старые вызовы кассы работают как раньше; при переданных
  `fiscalDocumentNumber`/`amountRub` включаются проверки `duplicate_fiscal` и `amount_mismatch`.
