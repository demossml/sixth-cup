### Побочные исправления, без которых P0 не работал

- `blockPayload` вырезал новые поля — `uppercase`/`locked` не сохранялись; теперь входят в payload.
- Схема темы принимала только 7 символов (`#RRGGBB`) — иначе альфа не сохранялась; расширено до 9.
- Клиентский резолв не повторял серверную чистку названия → редактор и PDF показывали разное; исправлено.
- Шрифты PDF искались только относительно бандла (`../../../assets/fonts`); при запуске `dist/index.js` из другой папки экспорт падал с `ENOENT`. Теперь каталог ищется по списку кандидатов.
- Выбор блока не переключал правую панель на «Блок» — теперь переключает.

## 5. Как проверить самому

```bash
npm install
npm run typecheck && npm run build
npm run test -w backend        # 827
npm run test -w frontend-admin # 191
npm run dev                    # client :5173 · admin :5174 · API :3000
```

В редакторе:

1. **Объёмы.** «Собрать лист из каталога» на каталоге с группами — «Капучино» даёт один блок с тремя ценами.
2. **Цвет.** Оформление → поле «Фон листа»: вписать `#12AB34`, потом `#12AB344D` — фон станет полупрозрачным, под полем появится контраст.
3. **Раскладка.** Shift+клик по двум блокам → в тулбаре появятся выравнивания; тянуть блок к центру — появится красная линия.
4. **Права.** Правый клик по блоку → меню; «Закрепить» и попробовать сдвинуть.
5. **Замеры.** Открыть `…/menu-layouts/<id>?perf=1`, подвигать блок, скачать PDF — числа появятся в консоли.
6. **Команды.** `⌘K` → «экспорт» → `Enter`. Сетка: кнопка «Сетка», рядом шаг и колонки.
7. **Миллиметры.** Выбрать блок → «Положение и размер» → «мм»; ввести X = 20 и вернуться в «%».
8. **Слои.** «Слои» → перетащить строку мышью; порядок и номера `zIndex` поменяются.
9. **Планшет.** Сузить окно до 1024 px: каталог уезжает в кнопку «Состав», лист и свойства остаются; до 430 px — снова вкладки.
10. **Стили.** Выбрать текстовый блок → «Стиль блока» → имя → «Создать», затем привязать второй блок; поменять кегль у одного — изменится и второй. «Оформление» → «Стили блоков» показывает число привязанных блоков.
11. **Экспорт в фоне.** «Экспорт PDF» → «Скачать PDF»: модалка закрывается, в правом нижнем углу видна задача с прогрессом, файл скачивается сам, ссылка остаётся в панели. Крестик закрывает задачу.
12. **Замечания.** Выбрать блок → «Замечания» в панели «Блок» → текст → Enter. На блоке появится оранжевая точка, в слоях — счётчик. Кнопка «Замечания» в шапке открывает список всех замечаний; в диалоге экспорта галочка «Замечания к блокам» кладёт их в PDF стикерами.
13. **Спуск полос.** «Экспорт PDF» → «Спуск полос» → «4 на A3 (2×2)»: в подписи видно, сколько выйдет листов; после сборки тост покажет масштаб («спуск 66 %»).

## 6. Риски и заметки

- **Группы объёмов.** Работает для товаров с `group_id`; если в каталоге вариант заведён без группы (три товара без `group_id`), они по-прежнему лягут тремя блоками — это данные, а не редактор.
- **Альфа в PDF** для фона смешивается с белой бумагой (печать не умеет прозрачность); для текста и акцента используется `fillOpacity`.
- **`?perf=1`** — диагностика, в обычной работе ничего не логирует.
- **Замечания в PDF** — аннотации-стикеры: их видно и можно открыть в Acrobat/Preview, но на бумаге они не печатаются (это свойство аннотаций PDF). Решённые замечания в файл не попадают.
- **Спуск полос и замечания несовместимы** в одном файле: при спуске лист масштабирован и повёрнут, аннотация уехала бы не туда, поэтому галочка замечаний блокируется. Если нужны оба — сначала обычный PDF с замечаниями, потом спуск.
- Прод-каталог в этой работе не менялся; проверки шли на копии базы (`/tmp/qa-menu.db`).
