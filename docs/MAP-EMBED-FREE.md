# Настоящая карта в PWA — бесплатно, без ключей и лицензий

Дата: 2026-11-08. Решение владельца: карта в клиентском приложении должна быть **бесплатной**.

## Что сделано

Экран «Выберите кофейню» показывает настоящую карту внутри приложения:
официальный виджет Яндекс.Карт `https://yandex.ru/map-widget/v1/` в iframe — тот же, что отдаёт
«Конструктор карт». Ключ API, аккаунт и договор не нужны.

- все кофейни с координатами — метками на одной карте;
- выбрал кофейню в списке → карта центрируется на ней и зумится (z=16);
- карта не перехватывает жесты страницы: пока гость не нажал «Нажмите, чтобы двигать карту»,
  свайп листает экран, а не карту;
- кнопка «Схема» возвращает прежнюю схему;
- карта не загрузилась / нет сети / у точек нет координат → автоматически показывается схема.
  Экран выбора кофейни работает всегда.

Кнопки **Google / Apple / Яндекс** остались и по-прежнему выбирают, в какое приложение отдать
маршрут («Маршрут · Google» и т. п.). Карта при этом одна — Яндекса, потому что она бесплатная.

## Почему не Google и не Apple

| Провайдер | Что нужно | Вердикт |
|---|---|---|
| Яндекс, виджет `map-widget` | ничего | **выбрано, 0 ₽** |
| Google `output=embed` | сейчас перенаправляет на Embed API, которому нужен проект Google Cloud с платёжным аккаунтом | не бесплатно на практике |
| Google Maps JS API | billing-аккаунт, 10 000 загрузок/мес бесплатно, далее $7/1000; оплата из РФ проблемная | не сейчас |
| Apple MapKit JS | Apple Developer Program $99/год + Maps ID + ключ | не бесплатно |
| Яндекс JS API 3.0 | лицензия ~195 000 ₽/год (до 500 запросов/сутки) | не сейчас |
| 2GIS MapGL | тариф/договор | не сейчас |
| MapLibre + тайлы | тайлы надо оплачивать или хостить самому | не сейчас |

## Что нужно от владельца, чтобы карта была

1. В админке у каждой точки заполнить **координаты** (Касса → точка → витрина: широта/долгота).
   Без координат показывается схема — это осознанный фолбэк, а не баг.
2. Проверить на телефоне: Меню → «Выберите кофейню» → карта с метками.

## Ограничения (честно)

- Виджет рисует брендинг Яндекса («© Яндекс», кнопка «Пробки», реклама на больших размерах) —
  это плата за бесплатность. В нашем размере 210 px реклама не показывается.
- Нужен интернет: тайлы не кэшируются в service worker (лицензия виджета этого не разрешает).
  Офлайн → схема.
- Внешний iframe в PWA: политику конфиденциальности стоит дополнить строкой, что при показе карты
  браузер обращается к Яндексу.

## Файлы

- `frontend/src/lib/mapEmbed.ts` — сборка URL виджета, центр/зум по всем точкам (+ тесты).
- `frontend/src/components/map/StoreMapEmbed.tsx` — iframe, лоадер, «нажмите, чтобы двигать»,
  кнопка «Схема», таймаут 6.5 с → фолбэк на схему.
- `frontend/src/components/map/StoreMap.tsx` — прежняя схема, теперь фолбэк.
