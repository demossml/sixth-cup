# Мини-игра «Собери альпаку»

## Поток
1. `POST /api/game/start` (JWT) → `sessionId` (нужен интернет).
2. Играть можно офлайн, пока сессия жива (~24 ч).
3. `POST /api/game/claim` — **единственное** место начисления кэшбэка.
4. Офлайн: claim в `localStorage` (`sc_game_pending_claims`), flush при следующем заходе.

## Награды (UTC день, 1 claim с ненулевым reward)
| Этап | Кэшбэк |
|------|--------|
| 1 | 0 |
| 2 | 30 коп. |
| 3 | 50 коп. |

## Антифрод
- Сессия привязана к userId
- Идемпотентный claim по sessionId
- Этап ≥2 и duration &lt; 4 с → 400
- Лимит 1 ненулевая награда / день / user
