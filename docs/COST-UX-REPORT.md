## Как проверить на телефоне

1. `npm run dev -w frontend-admin` → открыть `/cost` с телефона в той же сети.
2. **Импорт:** «Загрузить» → вкладка «Вставить текст» → пример выше → «Импортировать текст».
   Должно: toast, переход в «Дозаполнить», баннер «N позиций без цены», URL `?focus=missing`.
3. **Дозаполнить:** чип «Без цены» активен, красные карточки; тап по карточке → sheet →
   ввести цену → «Сохранить» → карточка становится белой, счётчик на вкладке уменьшается.
4. **Удаление:** sheet → «Удалить» → подтверждение; для ингредиента из рецепта появится
   сообщение сервера «используется в рецептах: …».
5. **Рецепты:** открыть рецепт — на телефоне останется только редактор, «← К списку» возвращает
   к списку; строки без цены красные, сумма «—»; панель сохранения липнет снизу.
6. **Сводка:** чип «Только проблемы» фильтрует; CSV выгружает видимые строки.
7. **Deep link:** открыть `/cost?focus=missing` напрямую — сразу «Дозаполнить» и фильтр без цены.

## Ограничения

- Таблицы Excel-вида на телефоне заменены карточками (`DataTable`), но на планшете ≥768px
  всё ещё таблица — это осознанно.
- Фильтр по категориям — чипы, без поиска внутри категории (поиск по названию остаётся).
- Сортировка рецептов/ингредиентов остаётся серверной, как была.
- `spec.zip` (vanilla-прототип) не копировался: вёрстка на React + `ui/kit`.
