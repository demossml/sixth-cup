# Рекомендации на кассе (upsell)

**Где в админке:** Касса → карточка точки → «Рекомендации на кассе». Есть и общий блок
(над списком точек) — значение по умолчанию для точек без собственной настройки.

**На точку:** да. `storeUuid` — точка Эвотора; другие точки не затрагиваются.

**Рубильник:** «Показывать рекомендации на кассе» (`enabled`). По умолчанию **выключено**:
каталог отдаёт пустые `upsell` / `upsellDefault`, касса блок не показывает — в том числе старые APK.

**Списки:**
- «К любому заказу» (`defaultProductIds`) — порядок = порядок на кассе, максимум 12;
- «рекомендовать вместе с этим» (`byProductId`) — по товару, на кассе до 6 позиций.

**Что не трогает:** молоко, сиропы, схемы добавок к напитку (`toppings` / `config.addons`),
«Фокус» (`featured`, `#focus`/`#combo`) и меню кассы (порядок вкладок). Добавки из категории
«Добавки» в рекомендации не попадают.

**Как доезжает на кассу:** обновление каталога — терминал тянет сам (до ~60 с) или кнопкой
«Синхронизировать каталог» в карточке точки.

**APK:** 5.3.20+ читает `upsell.enabled` / `upsellEnabled`; более старые версии просто получают
пустые массивы и не показывают блок.

**Тег `#upsell` в description Эвотора** больше не источник правды: рекомендации задаются только
здесь. `upsell` в каталоге формируется исключительно из этой настройки (автопул «все не-чашки» удалён).

**API:**
- `GET /api/admin/cashier/upsell?storeUuid=…` — настройка + справочник товаров для выбора;
- `PUT /api/admin/cashier/upsell` — `{ storeUuid?, enabled, defaultProductIds?, byProductId? }`;
- `DELETE /api/admin/cashier/upsell?storeUuid=…` — сброс точки на общую настройку.

**Хранение:** `app_settings` → `cashier_upsell:<storeUuid>` (и `cashier_upsell` — общая).
Битый JSON читается как «выключено и пусто», каталог не падает.

**Не деплоить прод без команды владельца.** После выкладки на терминале обновить каталог.
