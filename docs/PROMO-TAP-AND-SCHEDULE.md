# Акция на главной: действие по тапу и расписание (CON-1)

Раздел админки: **Контент** (`/marketing`) → вкладка «Контент PWA».
Плейсмент для карточки на главной: **«Карточка под QR на главной»** (`home_feature`).

## Что настраивается

| Поле админки | Колонка в БД | Что делает |
| --- | --- | --- |
| Заголовок | `title` | Заголовок карточки и модального окна |
| Текст | `body` | Подпись на карточке и текст в окне (переносы строк сохраняются) |
| CTA | `cta_label` | Подпись нижней кнопки в окне (пусто → «Открыть меню») |
| Бейдж | `badge` | Чип на медиа: Новинка / Хит / Сезон |
| Фото или видео | `image_url`, `media_type` | Медиа карточки и окна |
| **Что делать по тапу** | `tap_action` | `modal` — открыть описание в окне; `product` — перейти к товару; `menu` — открыть меню |
| ID товара | `product_id` | Куда вести при `tap_action='product'` и по кнопке в окне |
| **Когда показывать** | `time_from`, `time_to` | Окно по времени суток |
| Порядок | `sort_order` | Меньше = выше (совпадает с сортировкой на сервере) |
| Дней действия | `starts_at`, `ends_at` | Календарный срок жизни материала |

## Окно показа по времени

- Границы — **минуты от полуночи** (420 = 07:00), `NULL` + `NULL` = показывать всегда.
- Пресеты в админке: «Весь день», «Утро 06:00–12:00», «Обед 12:00–17:00», «Вечер 17:00–23:00», «Своё время».
- Полуинтервал `[from, to)`: 06:00–12:00 показывается в 06:00 и исчезает в 12:00.
- Если конец меньше начала — окно **через полночь** (например 22:00–02:00).
- Равные границы трактуются как «весь день» — защита от кривого ввода.
- Считается по **часам телефона гостя**, поэтому карточка появляется и исчезает даже из кэша, без сети. Экран пересчитывается раз в минуту (`useNow(60_000)`).

Логика окна — чистая функция `frontend/src/lib/dealWindow.ts` (`isVisibleAt`, `windowLabel`), покрыта тестами на утро/обед/вечер/полночь/частичные границы.

## Действие по тапу

| `tap_action` | Что видит гость |
| --- | --- |
| `modal` (по умолчанию) | Открывается окно акции: медиа, заголовок, текст, кнопка. Кнопка ведёт к товару (если задан `product_id`), иначе в меню. |
| `product` | Сразу переход на `/menu/{product_id}`. Без `product_id` ведёт в меню. |
| `menu` | Сразу переход на `/menu`. |

Окно (`frontend/src/components/PromoSheet.tsx`): закрывается крестиком, тапом по затемнению и клавишей Escape; пока открыто — страница не скроллится; `role="dialog"`, `aria-modal`, `aria-label` с заголовком.

## Что изменилось на главной

- Карточки рисуются **только** для плейсмента `home_feature`. Старый плейсмент `home` больше не показывается: он дублировал фразу «6-й стакан — в подарок» из шапки.
- Нет подходящих по времени материалов и нет купонов — секции нет совсем (никакой заглушки).
- Одна карточка — широкая, с медиа слева; две и больше — рельс, медиа сверху.

## Миграция

`backend/src/db/migrations/067_promo_tap_and_window.sql` (+ откат `rollback/067_promo_tap_and_window_rollback.sql`):

```sql
ALTER TABLE promos ADD COLUMN tap_action TEXT NOT NULL DEFAULT 'modal';
ALTER TABLE promos ADD COLUMN time_from INTEGER;
ALTER TABLE promos ADD COLUMN time_to INTEGER;
UPDATE promos SET tap_action = 'product' WHERE product_id IS NOT NULL;  -- сохранить прежнее поведение
```
