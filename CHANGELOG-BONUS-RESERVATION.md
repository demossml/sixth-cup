# Бонусы: резервация на сервере (миграции 011, 012)

Backend
- QR клиента = только удостоверение (id, kid, i, exp; без баланса). TTL по умолчанию 30 дней (CARD_QR_TTL_SEC).
- `POST /api/devices/loyalty/resolve` (только с EVOTOR_PROXY_TOKEN, иначе 403/503): проверка подписи, актуальное состояние, резервация бесплатного/кэшбэка на 90 с (RESERVATION_TTL_SEC). Уникальный частичный индекс: одна активная резервация на карту.
- SellHandler: RESERVED/EXPIRED→CONSUMED атомарно по `sc.op`; без резервации бонус не списывается, стакан засчитывается. Ввод номера карты вручную — только начисление.
- PAYBACK: пропорциональный откат (стаканы, бесплатные, кэшбэк, реферальные 3%), накопительно по нескольким возвратам.
- Закрыта утечка `GET /api/loyalty/card/:code`.
- Опрос Эвотора: курсорная пагинация, сырой JSON документа больше не сохраняется.
- `/api/sync` и `/api/loyalty/card`: cupsTowardFree, freeAvailable, fromFriendsRub, friendsCount.
- Сохранение аккаунта: `POST /api/auth/recovery`, `POST /api/auth/restore` (хранится только хэш секрета).

PWA
- Главный экран по n.md: QR, «N из 5» + подарок, кэшбэк, «Пригласить друга», «От друзей получено +N ₽» и число друзей (без разбивки), баннер «Сохраните свой аккаунт…», сохранение/восстановление по QR в профиле. Меню, акции, закладки не менялись.
- Убрана кнопка «Сканировать чек» (старая офлайн-схема).

Env: EVOTOR_PROXY_TOKEN обязателен для resolve; EVOTOR_PROXY_ENFORCE=1.
