# Размеры (объёмы) товара — одна карточка в админке, N SKU на кассе

## Модель

| Слой | Что хранится |
|---|---|
| `product_groups` | витринная карточка: имя, фото, категория, описание, схема добавок |
| `products` | по-прежнему торгуемый SKU: своя цена, свой `evotor_uuid`, `group_id`, `variant_label`, `variant_sort` |

Одна карточка «Капучино» + размеры «200 мл — 200 ₽», «300 мл — 300 ₽» → при сохранении создаётся
N продуктов с именами `Капучино 200 мл`, `Капучино 300 мл`. На кассе это разные позиции номенклатуры
Эвотор, у каждой свой UUID, цена и `article_number=sc-<productId>`.

Товары без `group_id` работают как раньше — обратная совместимость полная.

## HTTP API

- `GET /api/admin/product-groups` — группы с вариантами.
- `POST /api/admin/product-groups` — создать/обновить карточку с размерами (`variants[]`).
  Размеры, которых больше нет в запросе, не удаляются: `available=0` (историю чеков не рвём).
  Дубли названий размеров и пустой список → 400.
- `DELETE /api/admin/product-groups/:id` — «разъединить»: SKU остаются отдельными товарами.
- `GET /api/directory` — добавлены `productGroups[]` и поля `groupId` / `variantLabel` / `variantSort` у товаров.
- `GET /api/devices/catalog` — добавлен `groups[]` (`{ id, name, imageUrl, categoryId, description, variants: [{ productId, evotorUuid, label, price, priceRub, sizeValue, sizeUnit, countsAsCup, freeEligible }] }`).
  Плоский `products[]` остаётся полным — старые версии APK работают без изменений.

`groups[]` в каталоге содержит только карточки с **2+ доступными** вариантами.

## UI

- **Админка → Меню → товар**: блок «Размеры и объёмы» (объём, цена, единица), «Добавить размер»,
  «Разъединить». Кнопка «Добавить размеры» у обычного товара превращает его в карточку: текущий SKU
  становится первым размером (его Evotor-UUID сохраняется).
- **PWA → Меню**: одна плитка на карточку, под именем список объёмов, цена «от …»; в карточке товара —
  чипсы объёмов, при выборе меняется цена и объём.
- **Касса (APK, отдельный репозиторий)**: одна плитка на группу, выбор размера подставляет
  `evotorUuid` варианта в `Position`. Контракт описан в `ANDROID_INTEGRATION_CONTRACT.md` и
  `docs/DEVICE-CATALOG-API.md`.

## Ограничения

- Цена — целые рубли (`products.price INTEGER`).
- Аналитика по товарам считается по SKU; свод по карточке (`group_id`) пока не сделан.
- В Evotor уезжает N отдельных продуктов: следите за размером каталога на точке.
