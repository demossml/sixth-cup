# Очистка номенклатуры Эвотор + заливка из 6.7

Как «почистить кассу» в 1С, но через Cloud API.

## API
`POST /api/admin/evotor/stores/:storeUuid/wipe-catalog` (X-Admin-Token)
Только если `sync_enabled=1`.

Шаги:
1. GET все товары магазина в облаке
2. DELETE (пакетами до 1000 id) — официальный DELETE /stores/{id}/products?id=
3. Очистить `product_store_links` для store
4. pushToStore из локальных products 6.7

## UI
Админка → Точки → у точки с галочкой sync: кнопка «Очистить Эвотор и залить заново».

## Важно
Если Cloud по-прежнему отвечает 403 — удаление тоже не пройдёт. Сначала установка приложения на кассу / права токена.
После успеха на кассе: Ещё → Обмен → Загрузить в терминал.
