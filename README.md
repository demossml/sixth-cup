# Шестой стакан — offline-first PWA лояльности

Студенческий проект: полноценное приложение лояльности для кофейни.

## Механики

1. **Каждый 6-й стакан бесплатно**
2. **Реферальный кэшбэк 3%** с покупок друга (навсегда)
3. Купоны и акции (офлайн после синхронизации)

## Стек

Turborepo · Hono + SQLite · React + Vite + Tailwind + PWA · Lucide icons · Ed25519

## Запуск

```bash
npm install
npm run icons -w frontend
npm run dev
```

| URL | Назначение |
|---|---|
| http://localhost:5173 | Клиент |
| http://localhost:5173/cashier | Касса (код `DEMO1234`) |
| http://localhost:5173/admin | Админ-панель (токен `dev-admin`) |
| http://localhost:3000 | API |

## Offline

После первого входа (SMS) карта, стаканы, купоны и списание кэшбэка работают **без интернета** через QR-обмен с кассой.

## Что уже сделано (поверх прототипа)

- Rate limit на SMS и блокировка подбора кода
- Веб-админка: статистика, кассы, товары, акции, споры
- Онбординг из 3 экранов
- Защита кассы от повторного скана карты
- UI в стиле Luckin (синий), иконки Lucide без эмодзи
