# Шестой стакан — offline-first PWA лояльности

Студенческий проект: приложение лояльности для кофейни.

## Механики

1. **Каждый 6-й стакан бесплатно** (5 оплаченных → 6-й в подарок)
2. **Реферальный кэшбэк 3%** — с каждой покупки приглашённого друга навсегда

## Стек

- Turborepo · Hono + TypeScript + SQLite (backend)
- React + Vite + TypeScript + Tailwind + PWA (frontend)
- Ed25519-подписи · QR-обмен · IndexedDB

## Быстрый старт

```bash
npm install
npm run icons -w frontend
npm run dev
```

- Frontend: http://localhost:5173
- Backend API: http://localhost:3000
- Касса: http://localhost:5173/cashier (код `DEMO1234`)

## Офлайн

Карта, накопление стаканов, бесплатный 6-й, купоны и списание кэшбэка работают **без интернета**.  
Интернет нужен только для первого входа (SMS) и синхронизации.

## Лицензия

Учебный проект. Не для коммерческого использования брендов третьих сторон.
